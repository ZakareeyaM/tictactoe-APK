# Tic Tac Toe (Android)

Simple Kotlin Tic Tac Toe app: you are X, the AI is O (minimax, with a 20% random move so it can be beaten).

## Get the APK (no Android Studio needed)

1. Push this folder to a GitHub repo (branch `main`).
2. Open the repo > **Actions** tab > **Build APK** run (about 3-5 minutes).
3. Open the finished run > **Artifacts** > download `tictactoe-debug-apk` (a zip containing `app-debug.apk`).
4. Move `app-debug.apk` to your phone and tap it to install. Android will ask you to allow "Install unknown apps" for your browser or file manager.

You can also run the build manually: Actions > Build APK > **Run workflow**.

## Build locally (optional)

With Android Studio: open this folder and press Run, or Build > Build APK(s).
